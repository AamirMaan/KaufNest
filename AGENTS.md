Quick summary: Boughtopia is a Next.js 16 + Tailwind v4 brand-awareness site for a Berlin
commerce studio that (1) already manages Amazon/eBay/Etsy/Shopify/TikTok stores and (2) is
building a bookkeeping platform that hasn't shipped yet. This repo is the marketing site only
— don't build product/dashboard functionality unless asked, and never present the mockup
dashboard image or its numbers as real.

```bash
npm run dev
npm run build
npm run lint
```
